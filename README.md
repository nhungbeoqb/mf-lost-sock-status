A single status update, no more than 120 characters, written in the voice of a lost sock that has ended up somewhere it should not be — in a police evidence bag, labelled Exhibit A, protesting its innocence while the footprints match.

## Run it

```sh
python3 main.py
```

Writes the status update to `/output/entry.txt`.
